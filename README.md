# 微信小助手 · 部署包说明（dist）

> 本文档描述发布文件 `dist` 目录的结构、用途、部署要求和使用说明。

---

## 一、目录结构

打包完成后，`dist` 目录包含以下内容：

```
dist/
├── 微信小助手.exe                # 主程序（入口，需管理员权限运行）
├── CWeChatRobot.exe              # 微信机器人注入组件（32 位）
├── DWeChatRobot.dll              # 微信机器人注入 DLL（32 位）
├── weixin_config.txt             # 配置文件（可编辑）
└── WeChat/                       # 自带绿色版微信（完整运行环境）
    ├── WeChat.exe                # 微信主程序
    ├── wechat_starter_v1.0.0兼容启动器.exe   # 微信启动器（启动微信用）
    └── ...                       # 微信其他运行文件
```

---

## 二、文件说明

| 文件 | 作用 | 是否可删 |
|------|------|----------|
| `微信小助手.exe` | 主程序，自动化流程入口 | 否 |
| `CWeChatRobot.exe` | 注册/清理微信机器人 COM 服务 | 否 |
| `DWeChatRobot.dll` | 微信注入 DLL，实现收发消息 | 否 |
| `weixin_config.txt` | 配置端口、回调地址、激活码等 | 否（可编辑） |
| `WeChat/` | 自带绿色版微信，随包分发 | 否 |
| `WeChat/wechat_starter_v1.0.0兼容启动器.exe` | 启动微信 | 否 |

---

## 三、部署要求

1. **管理员权限**：`微信小助手.exe` 必须以**管理员身份**运行（右键 → 以管理员身份运行）。程序会自检，非管理员会提示退出。
2**目录可移动**：`dist` 可放到任意位置（桌面、D 盘等），程序会自动定位同目录下的组件。

---

## 四、首次使用流程

运行 `微信小助手.exe`（管理员）后，自动执行：

1. **授权校验**：检查激活码/试用期（首次运行起免费试用 30 天）；
2. **启动微信**：使用 `WeChat` 目录下自带的兼容启动器启动微信；
3. **等待微信界面**：等待微信主窗口出现；
4. **后台守护版本号**：后台线程持续改写微信版本号（覆盖扫码登录过程）；
5. **等待扫码/确认**：
   - 若微信已登录 → 直接按回车继续；
   - 若未登录 → 扫码登录后按回车继续；
6. **注入**：注册并注入微信机器人组件；
7. **启动服务**：启动 HTTP API 服务（`19088` 端口）和消息监听服务。

---

## 五、配置文件（weixin_config.txt）

关键配置项：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `http_api_port` | `19088` | HTTP API 服务端口 |
| `hook_url` | `http://localhost:8080/stock/wechat/hook` | 消息回调推送地址 |
| `listen_port` | `10878` | 消息监听 socket 端口 |
| `notify_wxid` | `filehelper` | 启动通知目标 |
| `login_success_msg` | `微信机器人登录成功！` | 启动时发送的通知内容 |
| `license` | 空 | 激活码（填入后永久授权） |

## 六、激活说明

### 试用期
- 首次运行起 **30 天免费试用**；

### 激活
1. 程序启动时显示**本机机器码**
2. 提供机器码获取激活码(加qq 335675985)；
3. 把激活码填入 `weixin_config.txt` 的 `license=` 项；
4. 保存后重新运行程序，显示"注册码有效"即激活成功；
---

## 八、常见问题

### Q1：运行提示"需要以管理员身份运行"
→ 右键 `微信小助手.exe`，选择"以管理员身份运行"。

### Q2：提示"未找到打包自带的 WeChat"
→ `WeChat` 文件夹缺失或 `WeChat.exe` 不在该目录，请确保 dist 完整。

### Q3：提示"未找到兼容启动器"
→ `WeChat` 目录下缺少 `wechat_starter_v1.0.0兼容启动器.exe`。

### Q4：外部调用 `/api/sendTextMsg` 返回发送失败
→ 确认微信已登录、注入成功、目标 `wxid` 有效。发送到 `filehelper`（文件传输助手）用于测试。

### Q5：服务异常退出
→ 主程序会自动无限重启 HTTP API 和消息监听服务（每 5 秒，持续拉起）。
